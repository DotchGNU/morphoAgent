# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. All contributors and maintainers are expected to follow it in every project
space: issues, pull requests, discussions and reviews.

In short: be respectful and constructive, welcome people of every background and level of experience,
accept criticism of code and methods gracefully, and focus on what is best for the project and its users.
Harassment, personal attacks and publishing others' private information are not tolerated.

## Reporting

Report unacceptable behaviour privately to the project maintainers through the contact options of the
[repository owner](https://github.com/myLabTechnician). All reports are reviewed promptly and handled
confidentially. Maintainers who do not follow the code of conduct may face consequences determined by
the other project maintainers.
